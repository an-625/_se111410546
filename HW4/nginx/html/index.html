🐳 Docker 微服務系統展示

nginx 反向代理 ＋ Node.js / Rust / Python ＋ PostgreSQL

nginx :8080 node :3000 rust :8000 python :5000 postgres :5432

📦 系統架構

Browser ──► nginx:80 (web server + reverse proxy, 本頁)
              ├─ /               → 靜態前端 (html/)
              ├─ /health        → nginx 自檢
              ├─ /api/node/*   → api-node:3000   (Node.js 20 + Express)
              ├─ /api/rust/*   → api-rust:8000   (Rust + Axum)
              └─ /api/python/* → api-python:5000 (Python 3.12 + Flask)
                                  └─► postgres:5432 (PostgreSQL 16, db: microdb)
